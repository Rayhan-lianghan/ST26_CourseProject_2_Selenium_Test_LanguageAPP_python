# HSK Language App - Software Testing Project

## Project Overview
This repository contains the complete Software Quality Assurance (SQA) testing suite for the HSK Language Learning Application. The project includes automated functional testing and performance evaluation.

## Technical Stack
- **Testing Framework:** Selenium WebDriver
- **Backend:** Flask / SQLite3
- **Language:** Python

## Key Features
- **POM Design:** Decoupled UI locators for high maintainability.
- **Stress Testing:** Concurrent load simulation to identify system bottlenecks.
- **Defect Tracking:** Systematic logging of functional regressions.
